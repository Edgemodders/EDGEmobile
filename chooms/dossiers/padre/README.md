# Padre

Fixer, Heywood. Heywood's fixer. Faith, family, and favors.

- **Portrait:** Padre's face, shoulders up, in good light. It is their picture in the app.
- **Body:** Padre head to toe, standing, on a plain background if you can. Used for photos of them doing something.
- **Places:** where photos of them are taken. Each is an image in `places/` with a `.md` of the same name beside it.
