# EDGE<span class="y">mobile</span> docs

EDGEmobile is a phone operating system for Cyberpunk 2077, built as a [REDnode](https://edgemodders.github.io/REDnode/) app. The same phone shows in the game, drawn over it by REDnode's overlay, and on your real phone, as a web app you open from a QR code and can install to your home screen. Its home screen shows the mobile apps you install, which other modders can write. The first will be **Chooms!**, Night City's social feed.

| [Design](design.html) | How EDGEmobile is built: the two screens, connecting a real phone (tunnel, QR code, pairing), the OS and its home screen, mobile apps, installing on the phone, the phases |
