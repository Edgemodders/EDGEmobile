EDGEmobile gives your PC a private web address through Cloudflare, so your phone can reach the game from anywhere. Only a phone that scans the code shown here, and that you allow here, can connect. You can disconnect it at any time, and the address closes when the game does.

For that, EDGEmobile needs Cloudflare's tunnel program, cloudflared , from Cloudflare's GitHub releases ( MB). It is checked against the checksum pinned in EDGEmobile and kept in EDGEmobile's data folder.
