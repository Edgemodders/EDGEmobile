# Mobile apps

Installed mobile apps go here, one folder each, named by the app's id:

```
mobile-apps/
  chooms/
    mobile-app.json
    index.html
    icon.svg
```

EDGEmobile finds them and shows their icons on the phone's home screen, in the game and on the real phone. The manifest's fields and the `mobile` library apps use are still being designed: see [docs/design.md](../../docs/design.md), "Mobile apps".
